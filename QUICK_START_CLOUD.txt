STEP 1: MONGODB ATLAS SETUP (5 minutes)
================================================================================

1. Sign up: https://www.mongodb.com/cloud/atlas/register
2. Create FREE M0 Cluster:
   - Region: Mumbai (or closest to you)
   - Name: kle-alumni-cluster
   
3. Create Database User:
   - Username: kle_admin
   - Password: [Choose a strong password - SAVE THIS!]
   
4. Add Your IP:
   - Network Access → Add IP Address
   - Allow Access from Anywhere (0.0.0.0/0) for now
   
5. Get Connection String:
   - Click "Connect" → "Connect your application"
   - Copy the connection string
   - Example: mongodb+srv://kle_admin:<password>@cluster.xxxxx.mongodb.net/

================================================================================
STEP 2: UPDATE .ENV FILE (2 minutes)
================================================================================

Open: c:\Users\guru3\Downloads\WebTech\alumni\.env

Replace this line:
MONGODB_URI=mongodb://localhost:27017/kle-alumni-connect

With your Atlas connection string:
MONGODB_URI=mongodb+srv://kle_admin:YOUR_PASSWORD@cluster.xxxxx.mongodb.net/kle-alumni-connect?retryWrites=true&w=majority

⚠️ IMPORTANT: Replace <password> with your actual password!

================================================================================
STEP 3: INSTALL DEPENDENCIES (2 minutes)
================================================================================

- cloudinary (for image storage)

📊 CURRENT API ENDPOINTS (Already implemented!)
================================================================================

Authentication:
POST /api/auth/register    - Register new user
POST /api/auth/login       - Login user
POST /api/auth/forgot-password - Request password reset
POST /api/auth/reset-password - Reset password
GET  /api/auth/verify      - Verify JWT token

Students:
GET  /api/students/alumni      - Get alumni list
GET  /api/students/profile     - Get student profile
PUT  /api/students/profile     - Update student profile
GET  /api/students/connections - Get student connections

Alumni:
GET  /api/alumni/profile            - Get alumni profile
PUT  /api/alumni/profile            - Update alumni profile
GET  /api/alumni/connection-requests - Get connection requests
GET  /api/alumni/posts              - Get alumni posts

Admin:
GET  /api/admin/stats          - Get dashboard statistics
GET  /api/admin/users          - Get all users
PUT  /api/admin/users/:id/status - Update user status
DELETE /api/admin/users/:id    - Delete user
GET  /api/admin/posts          - Get all posts for moderation
PUT  /api/admin/posts/:id/approve - Approve/reject post

Posts:
GET  /api/posts                - Get all posts
POST /api/posts                - Create new post
POST /api/posts/:id/appreciate - Appreciate a post
POST /api/posts/:id/answer     - Add answer to post
DELETE /api/posts/:id          - Delete post

Connections:
GET  /api/connections          - Get all connections
POST /api/connections          - Send connection request
PUT  /api/connections/:id      - Update connection status
DELETE /api/connections/:id    - Delete connection

Messages:
GET  /api/messages             - Get all messages
GET  /api/messages/conversations - Get conversation list
POST /api/messages             - Send message
PUT  /api/messages/:id/read    - Mark message as read
DELETE /api/messages/:id       - Delete message

================================================================================
🆘 TROUBLESHOOTING
================================================================================

Error: "MongoNetworkError"
→ Check internet connection
→ Verify IP is whitelisted in MongoDB Atlas

Error: "Authentication failed"
→ Check username/password in connection string
→ Make sure you replaced <password> with actual password

Error: "Cannot find module 'cloudinary'"
→ Run: npm install

Server not starting:
→ Make sure .env file exists
→ Check PORT is not already in use (default: 5000)
→ Try: npm run dev instead of npm start
