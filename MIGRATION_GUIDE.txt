================================================================================

PHASE 1: MONGODB ATLAS SETUP (Cloud Database)
----------------------------------------------

Step 1.1: Create MongoDB Atlas Account
  → Go to: https://www.mongodb.com/cloud/atlas/register
  → Sign up for FREE (no credit card needed)
  → Create organization (e.g., "KLE Alumni")

Step 1.2: Create a Cluster
  → Click "Build a Database"
  → Choose M0 FREE tier
  → Select region closest to you (e.g., Mumbai for India)
  → Cluster name: "kle-alumni-cluster"

Step 1.3: Configure Database Access
  → Go to "Database Access" in left menu
  → Click "Add New Database User"
  → Create username/password (SAVE THESE!)
  → Example: username=kle_admin, password=SecurePass123

Step 1.4: Configure Network Access
  → Go to "Network Access" in left menu
  → Click "Add IP Address"
  → For development: Click "Allow Access from Anywhere" (0.0.0.0/0)
  → For production: Add your specific server IP

Step 1.5: Get Connection String
  → Go to "Database" → Click "Connect"
  → Choose "Connect your application"
  → Copy the connection string (looks like):
    mongodb+srv://kle_admin:<password>@kle-alumni-cluster.xxxxx.mongodb.net/
  
Step 1.6: Update .env File
  → Open: c:\Users\guru3\Downloads\WebTech\alumni\.env
  → Replace MONGODB_URI with your Atlas connection string
  → Replace <password> with your actual database password
  → Replace database name:
    
    MONGODB_URI=mongodb+srv://kle_admin:SecurePass123@kle-alumni-cluster.xxxxx.mongodb.net/kle-alumni-connect?retryWrites=true&w=majority

Step 1.7: Test Connection
  → Run: npm install
  → Run: npm run dev
  → Look for: "✅ MongoDB Connected Successfully"
  → If error, check username/password/IP whitelist

Step 1.8: Seed Initial Data (Optional)
  → Run: npm run seed
  → This will populate your cloud database with initial data

PHASE 2: CLOUDINARY SETUP (Image/File Storage)
-----------------------------------------------

Step 2.1: Create Cloudinary Account
  → Go to: https://cloudinary.com/users/register/free
  → Sign up for FREE (10GB storage, 25 credits/month)
  → Get credentials from dashboard

Step 2.2: Install Cloudinary SDK
  → Run in terminal:
    npm install cloudinary

Step 2.3: Add to .env File
  → Add these lines to .env:
    
    CLOUDINARY_CLOUD_NAME=your_cloud_name
    CLOUDINARY_API_KEY=your_api_key
    CLOUDINARY_API_SECRET=your_api_secret

Step 2.4: Create Upload Configuration
  → File already exists: server/middleware/upload.js (if not, create it)
  → See CLOUDINARY_SETUP.txt for implementation details
